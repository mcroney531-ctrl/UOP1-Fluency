# AI Fluency Strategy — Portfolio Edition

A standalone HTML strategic perspective on AI fluency in organizational learning. The experience retains its four pillars: Learners’ Reality, Keep Content Alive and Robust, The Bottleneck Factor, and Small and Subtle.

## View

Open `index.html` in a modern browser. The linked `westover.html` page is included alongside it.

## Implementation

Static HTML and CSS; no build tooling, runtime service, or authentication needed. Artwork is embedded in the HTML. External connections are limited to Google Fonts (with font fallback) and hyperlinks to public research sources. The Practitioner Support Tool is intentionally described without a link because it was developed for internal use.

## Source and evidence notes

The case examples have been generalized to avoid identifying organizational circumstances. Observations and proposed approaches are not presented as independently measured organizational outcomes. Research quotations, paraphrases, and numerical findings retain source context in the experience.

This portfolio edition contains no previous Git history.
